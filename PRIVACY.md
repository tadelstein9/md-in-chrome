# Privacy

Markdown in Chrome runs on your computer. It does not send your files
anywhere. It has no network permission and makes no network request.

It reads the markdown file you open. It writes only the files you ask
for: an edit copy, a clean copy, and a PDF. The original file is not
written.

The only thing it stores is a pointer, in the browser's IndexedDB, to
files you already opened, so they appear under Recents. Removing the
extension clears that list.

See the [source](https://github.com/tadelstein9/md-in-chrome).
