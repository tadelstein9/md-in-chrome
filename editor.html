    Markdown in Chrome

    A model hands you a file full of pound signs and asterisks. Open it here and read it the way it is meant to look — headings as headings, tables as tables. Fix what you find while you are looking at it. The original file does not change. Save writes an edit copy with the marks, a clean copy with the changes taken, and a PDF the office can open.

    Only the paragraphs you actually touch get rewritten. Everything else is saved exactly as it arrived, character for character.

    Open a folder lists hidden names such as .grok. In Chrome’s folder window type the folder you want, then Select. Linux: Ctrl+L. Windows: the path bar. Mac: Cmd+Shift+G. Do not pick Home. Chrome will not select it.
